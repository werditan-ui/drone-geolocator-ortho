# Геолокація відео з дрону за ортофотопланом

Цей проєкт дозволяє визначити приблизні GPS-координати місця зйомки з дрону, порівнюючи кадри відео з ортофотопланом.

## Що включено
- `geolocate_from_ortho.py` — основний Python-скрипт
- HTML-карта результату (`geo_map.html`) — генерується автоматично

## Вимоги
- Python 3.9+
- OpenCV
- NumPy
- rasterio
- folium

## Встановлення

```bash
pip install opencv-python numpy rasterio folium
```

## Запуск

```bash
python geolocate_from_ortho.py --video drone_video.mp4 --ortho orthophoto.tif --fps 1 --map geo_map.html
```

## Параметри
- `--video` — шлях до відео
- `--ortho` — шлях до ортофотоплану у форматі GeoTIFF
- `--fps` — частота вибірки кадрів (рекомендовано 1)
- `--map` — шлях до HTML-файлу карти

## Як це працює
1. Скрипт читає відео та вибирає кадри.
2. Завантажує ортофотоплан із геоприв’язкою.
3. Використовує ORB-алгоритм для пошуку схожих ознак між кадром та ортофотопланом.
4. Після знаходження відповідності переводить піксельні координати в географічні GPS-координати.
5. Зберігає результат у консоль і HTML-карту.

## Важливо
- Якість геолокації залежить від якості ортофотоплану та відео.
- Для кращих результатів використовуйте чітке відео з висоти, де видно контури доріг, річок, будівель або лісосмуг.
- Якщо результат слабкий, спробуйте використати ортофотоплан більш високої роздільної здатності.

## Приклад результату

```text
Результат геолокації:
Latitude: 50.450000
Longitude: 30.520000
Confidence: 0.82
```

## Де знайти ортофотоплан
- Sentinel-2 / USGS / OpenStreetMap tiles / локальні GeoTIFF-файли
- Переважно формати: `.tif`, `.tiff`

## Підсумок
Цей проєкт є базовим каркасом для геолокації з дрону по ортофотоплану і може бути розширений для більш точного matching, використання SIFT/FLANN, кращої стабілізації кадрів або інтеграції з OSM.
